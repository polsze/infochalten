
# InfoChalten — App Promotional Website

Bilingual promotional website developed to introduce and showcase **InfoChalten**, a digital platform designed to connect tourists and local residents with businesses, services, events, and useful information about El Chaltén, Patagonia, Argentina.

🌐 **Live Website:** https://www.infochalten.com/

## 📌 About the Project

The website was built to present the InfoChalten application, explain its features, and guide users through the installation process on mobile devices.

It provides an accessible overview of the platform, highlighting local services and tourism-related information through a responsive and visually engaging interface.

## 🚀 Main Features

- Bilingual interface (Spanish and English).
- Responsive design for desktop and mobile devices.
- Animated UI elements and scroll-based transitions.
- Lazy loading of React components.
- Dedicated sections presenting application features.
- Step-by-step mobile installation instructions.
- Custom language context and dynamic content.
- Image lazy loading and viewport-based animations.
- Contact section and external application links.

## 🌎 Platform Categories

- Accommodation and hospitality.
- Restaurants and gastronomy.
- Transportation services.
- Local stores and businesses.
- Events and activities.
- Trekking and outdoor information.
- Local artists and organizations.

## 🛠️ Technologies & Libraries

- **Frontend:** React 18, JavaScript, Vite 4
- **Styling:** Tailwind CSS 3
- **Routing:** React Router DOM
- **Animations:** Framer Motion, AOS
- **UI & Icons:** Heroicons, Iconify
- **Scroll & Visibility:** React Scroll, React Intersection Observer
- **Image Optimization:** React Lazy Load Image Component
- **SEO:** React Helmet
- **Deployment:** GitHub Pages

## 🔧 Technical Implementation

- Built a component-based architecture using React.
- Implemented bilingual content management through React Context.
- Used React Lazy and Suspense for component-level code splitting.
- Integrated viewport detection for scroll-triggered animations.
- Implemented responsive layouts and custom Tailwind CSS breakpoints.
- Added lazy loading for images to improve resource loading.
- Configured automated production builds using Vite.

## 🎯 Project Goals

- Promote the InfoChalten application.
- Make local information more accessible to tourists and residents.
- Showcase the platform's features through an engaging interface.
- Provide clear installation instructions for mobile users.
- Deliver a bilingual and responsive browsing experience.
